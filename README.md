## 핵심 원칙
**저점에서 분할매수 → 목표 수익률 도달 시 분할매도 → 충분히 하락하면 재매수**

- **거래소**: Upbit KRW 마켓 (pyupbit)
- **대상**: 28종목 — 대형주 + 중소형 (Tier A/B/C)

- **자동매매**: Oracle Cloud VM (피크 15분 / 일반 30분, 24/7)
- **알림**: 텔레그램 신호 + 차트 이미지

## v5.20 변경사항 (신호매도 Churn 방지)
- **MIN_SIGNAL_EXIT_HOURS 8h**: 신호매도 최소 보유시간 (동일가 매도 방지)
- **MIN_SIGNAL_EXIT_PNL 1.0%**: |PnL| < 1% 구간 신호매도 차단 (수수료 소모 방지)
- **SIGNAL_EXIT_THRESHOLD -15**: 더 강한 반전만 매도 허용
- **TP1 3% / TP2 7% 복원**: 신호매도 전 분할매도 발동 보장
- **SL 5%**: 노이즈 SL 방지 + 손실 제한 절충
- **백테스트 검증**: Churn 28→0건, 승률 64→70%, 총수익 +6.9%p 개선

## 매수 전략 (분할매수)
1. **1차 매수 (60%)**: 매수 신호 시 포지션의 60%만 진입
2. **2차 매수 (DCA)**: -3% 추가 하락 시 나머지 잔여분 매수 → 평균단가 개선
3. 가격 상승 시 → 60%로 TP1(+3%) 익절, 잔금은 다른 종목에 활용

## 매도 조건 (분할매도 + Churn 방지)
1. **TP1 +3%**: 60% 부분매도 (수익 확정)
2. **TP2 +7%**: 나머지 전량매도
3. **트레일링**: +5% 활성 → -2% 콜백
4. **손절 -5%** (최소 보유 2시간 후)
5. **앙상블 신호 반전** — 8h 이상 보유 + |PnL| ≥ 1% 조건 충족 시만
6. **시간 스탑** (7일 이상 보유)

## 리스크 관리
- **RSI 매수 상한**: RSI > 55 → 매수 절대 불가
- **최소 진입 점수**: 5/10점 이상 (다중지표 복합 확인)
- **손절 쿨다운**: 손실 매도 후 4시간 재진입 금지
- **서킷브레이커**: MDD 15% 또는 일일 낙폭 8% 시 매매 중단
- **일일 손절 한도**: 3% 또는 2회 초과 시 신규 매수 차단
- **노출 한도**: 총 80% / 종목당 12% / 최대 6종목
- **거래대금**: 24h ≥ 10억원
