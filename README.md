# 🪙 Coin Alert v4.0 — Upbit KRW 자동매매 (평균회귀)

stock-alert v7.6 기반 → v4.0 평균회귀/스윙 트레이딩으로 전면 재설계.

## 핵심 원칙
**저점에서 매수 → 목표 수익률 도달 시 매도 → 충분히 하락하면 재매수**

## 특징
- **거래소**: Upbit KRW 마켓 (pyupbit)
- **대상**: 20종목 — 대형주 + 중소형
- **전략**: 3-전략 앙상블 (평균회귀 55-65% + 추세확인 5-15% + 모멘텀예측 30%)
- **자동매매**: Oracle Cloud VM (피크 15분 / 일반 30분, 24/7)
- **알림**: 텔레그램 신호 + 차트 이미지

## v4.0 변경사항 (평균회귀 전면 재설계)
- **breakout 전략 제거**: 고점 돌파 매수가 추격매매의 근본 원인 → 완전 제거
- **평균회귀 중심 가중치**: mean_revert 55-65% (기존 10-30%) → 저점 매수 강화
- **RSI 하드 매수 차단**: RSI > 60이면 어떤 신호든 매수 불가 (비타협)
- **고정 목표 수익률**: +6% 도달 시 매도 (트레일링 스탑 제거)
- **고정 손절**: -4% 도달 시 손절 (R:R 1:1.5)
- **매도가 기억**: 매도 후 5% 하락해야 재매수 허용 (추격매매 방지)
- **포지션 집중**: 최대 3종목 동시 보유, 종목당 35%
- **피라미드/부분 익절 제거**: 단순 명확한 로직

## 설정 방법

### 1. 환경변수 (VM: ~/coin-alert/.env)
```
TELEGRAM_BOT_TOKEN   텔레그램 봇 토큰
TELEGRAM_CHAT_ID     텔레그램 채팅 ID
UPBIT_ACCESS_KEY     Upbit Open API 접근 키
UPBIT_SECRET_KEY     Upbit Open API 시크릿 키
INITIAL_CAPITAL      초기 자본금 (KRW, 예: 2000000)
```

### 2. 로컬 테스트
```bash
pip install pyupbit pandas numpy requests matplotlib mplfinance
python coin_alert.py
```

## 리스크 관리
- **RSI 매수 상한**: RSI > 60 → 매수 절대 불가
- **고정 손절**: -4% (트레일링 스탑 대신 단순 명확)
- **손절 쿨다운**: 손실 매도 후 24시간 재진입 금지
- **매도가 기억**: 매도 후 5% 하락 전까지 재매수 불가
- **최소 보유**: 3시간 이내 매도 차단
- **서킷브레이커**: MDD 15% 또는 일일 낙폭 8% 시 매매 중단
- **노출 한도**: 총 80% / 종목당 35% / 최대 3종목
- **시간 스탑**: 10일 이상 보유 시 자동 청산

## 매도 조건
1. **목표 수익률 +6%** 도달
2. **손절 -4%** 도달 (최소 보유 3시간 후)
3. **앙상블 신호 반전** (CLOSE/STRONG_CLOSE)
4. **시간 스탑** (10일 이상 보유)
